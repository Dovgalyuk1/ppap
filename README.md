# PPAP — Pen Pineapple Apple Pons

Одностраничный статический сайт под мемкоин $PPAP. Без сборки.

Деплой: залить папку в GitHub-репозиторий → Vercel → Add New Project → Import.
Build command не нужен, Output Directory — корень.

Контракт и ссылка на X меняются в блоке SETTINGS в самом верху `index.html`.
